
# Trade Bot
This DApp, built with Next.js, Ethers.js, Wagmi, RainbowKit, and React Query, enables users to seamlessly interact with the Ethereum testnet. Core features include sending ETH and ERC-20 tokens, swapping between tokens, and accessing a faucet that dispenses 1 QTK every 6 hours. To use all functionalities, simply connect your wallet.



## Run Locally

Clone the project

```bash
  git clone https://github.com/asingh0044/Trade_bot/tree/feat/connect-wallet
```

Go to the project directory

```bash
  cd Trade_bot
```

Install dependencies

```bash
  npm install
```

Start the server

```bash
  npm run dev
```


## Environment Variables

To run this project, you will need to add the following environment variables to your .env file

`NEXT_PUBLIC_PROVIDER_URL`

`NEXT_PUBLIC_ETHERSCAN_API_KEY`

`NEXT_PUBLIC_ALCHEMY_API_KEY`

`NEXT_PUBLIC_CAPTCHA_SITE_KEY`

`NEXT_PUBLIC_ETHERSCAN_TRASACTION_URL`

`NEXT_PUBLIC_ETHERSCAN_BASE_URL`
